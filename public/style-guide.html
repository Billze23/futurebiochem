01 — Foundation

Brand Identity

The FutureBioChem wordmark combines two weights of Space Grotesk. "FUTURE" and "CHEM" render in white at full weight; "BIO" renders in the brand cyan to create a natural visual break and emphasize the biological core of the brand.

Primary — Dark Background

⚠ Wordmark Usage Rules

Never recolor the full wordmark in a single flat color. Do not use on light backgrounds without a dark backdrop. Always maintain clear space equal to the cap-height of the "F" on all sides. Do not stretch, condense, or add effects to the wordmark.

03 — Foundation

Typography

Two typefaces define the FutureBioChem visual voice. Space Grotesk carries authority and scientific precision in headings. Manrope provides warmth and readability across all body and UI text.

Display & Headings

Space Grotesk

A geometric sans-serif designed for digital interfaces. Used for all H1–H3 elements, the brand wordmark, data numerals, and navigation labels. Available weights: 300, 400, 500, 600, 700.

font-family: 'Space Grotesk', sans-serif;
Body & UI

Manrope

A humanist sans-serif that excels at small sizes and long-form text. Used for all body copy, form labels, button text, table cells, and descriptive UI elements. Available weights: 300–800.

font-family: 'Manrope', sans-serif;

Type Scale

04 — Components

Buttons

Three button variants handle different interaction priorities. Use solid cyan for the primary action on any surface, outline for secondary actions, and ghost for low-priority or tertiary actions.

Button Variants
/* Primary */ background: #00E5FF; color: #000; font-weight: 700; border-radius: 0.5rem; padding: 0.75rem 1.5rem; /* Secondary */ border: 2px solid #00E5FF; color: #00E5FF; background: transparent; border-radius: 0.5rem; /* Ghost */ background: rgba(255,255,255,0.05); color: #8891A4; border: 1px solid rgba(255,255,255,0.08);
Tab Buttons
/* Active tab */ color: #00E5FF; border-bottom: 2px solid #00E5FF; background: transparent; /* Inactive tab */ color: #8891A4; border-bottom: 2px solid transparent;

10 — Standards

Motion & Transitions

All transitions use a single 0.3s ease curve. Never use bounce, spring, or elaborate keyframe animations — the interface should feel precise and scientific, not playful.

Transition Standard
transition: all 0.3s ease; /* Applied to: buttons, cards, nav items, tab indicators, border colors, box shadows, opacity, background fills */ /* Accordion panels use max-height for smooth expand: */ transition: max-height 0.3s ease;
Glow — Cyan
box-shadow: 0 0 20px rgba(0,229,255,0.25);
Glow — Gold
box-shadow: 0 0 20px rgba(255,219,60,0.2);

11 — Standards

Icons

All icons use the Material Symbols Outlined library with thin weight settings. Icons appear in secondary text color unless they are part of an active or accent element.

Icon Library & Usage
/* Google Fonts import */ <link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined: wght,FILL@100..700,0..1&display=swap" rel="stylesheet"/> /* Usage in HTML */ <span class="material-symbols-outlined">science</span> <span class="material-symbols-outlined">medication</span> <span class="material-symbols-outlined">calculate</span> /* CSS variation settings */ .material-symbols-outlined { font-variation-settings: 'FILL' 0, 'wght' 400, 'GRAD' 0, 'opsz' 48; }

Icon Color Rule

Default icons render in #8891A4. Icons within active sidebar items or cyan UI elements render in #00E5FF.

12 — Standards

Do's & Don'ts

These guardrails keep the FutureBioChem interface consistent, legible, and on-brand.

✓ Do

  • Use Space Grotesk for all numerical data values displayed in the UI
  • Maintain the 0.3s ease transition on all interactive elements
  • Use the gold accent (#FFDB3C) exclusively for warnings and premium items
  • Keep badge text to 3 words or fewer, always uppercase
  • Use uppercase + wide letter-spacing (0.08–0.16em) for section labels
  • Pair every cyan glow with rgba(0,229,255,0.15–0.25) opacity

✗ Don't

  • Use light backgrounds — the entire interface is dark-first
  • Use the cyan accent for body text — only for values, labels, and CTAs
  • Mix more than two typefaces anywhere on a single screen
  • Apply drop shadows — use glow effects (box-shadow with rgba) only
  • Use bounce, spring, or elaborate keyframe animations
  • Alter the "BIO" cyan split in the wordmark or render it flat single-color
